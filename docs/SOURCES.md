## Not catalogued as standalone cases

- 官方或文章中的能力概述、评测数字和价目，写在 README 正文并标明出处，不单独拆成案例。
- 冷逸文中标题写「13 个玩法」，正文按能力分组，并未给出 1–13 的命名清单，因此不编造 13 条玩法名。
- 冷逸转述的「官方 37 轮」示例，本仓库未在官方产品页或发布博文中核到「37 轮」这一表述，故不单列官方案例；相关句式收入提示词一节，并归给该文。
- 向阳乔木文中提到的他人对比视频（X 上的 100 轮对照、小互换装测试、豆姐官方宣传视频）不是作者本人的实测，不单列。
- 社区文章称火山引擎 API 将于当周上线；本仓库未核验公开 API 地址，也不把尚未确认的接口写成已上线。
- 卡尔的AI沃茨、夕小瑶编辑部转述的火山引擎 2K 改图约两毛八等价格，以及冷逸文中当时的即梦限时福利，只在 README 中按「文章引述 / 当时宣传」说明，不作为案例，也不当作已核实的官方长期定价或长期政策。
